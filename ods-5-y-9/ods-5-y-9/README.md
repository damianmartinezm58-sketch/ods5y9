# Industry, Innovation & Equality · SDG 5 + SDG 9

Interactive awareness website about **SDG 5 (Gender Equality)** and **SDG 9 (Industry, Innovation and Infrastructure)** from Guanajuato, Mexico: a 3D hall where half a sun completes as you walk in, sourced data, projections to 2050, four mini games (trivia, a 3D fair city, myth or fact, memory game) and a pledge generator.

- **Run it:** open the folder in Visual Studio Code → right-click `index.html` → **Open with Live Server** (or double-click `index.html`).
- **Edit the content:** change `base_de_datos.xlsx` and run `python3 actualizar_datos.py`.
- **Full step-by-step guide (Spanish):** [GUIA_PASO_A_PASO.md](GUIA_PASO_A_PASO.md).
